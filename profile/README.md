# Rafters

The design intelligence protocol.

From service design to shipped code -- one system, zero handoffs.

## What Rafters Is

AI agents don't have taste. They guess at colors, spacing, hierarchy. Rafters encodes a designer's judgment into queryable intelligence so AI reads decisions instead of guessing.

**The pipeline:**

1. **Service Design** -- blueprints, ecosystems, moments of truth as structured data
2. **Studio** -- design your design system. Spacing progressions, type scales, color relationships, motion philosophy. The first tool in this category.
3. **Composites** -- reusable UI patterns with embedded intelligence (cognitive load, do/never rules, trust patterns)
4. **Registry** -- `pnpx rafters add` delivers components into your framework with intelligence attached
5. **MCP Tools** -- AI agents query the protocol directly: vocabulary, patterns, components, tokens, cognitive budget
